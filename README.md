# Ranking

F&O Friday Ranking Tracker — upload an Excel file, pick a base date, and download ranked results with weekly Friday top-20 summary.

## Run locally

```bat
cd fo-ranking-tracker
run.bat
```

Open http://127.0.0.1:8000

## Features

- Base/current prices and % diff for NSE stocks
- Friday rank columns with color bands (1–20 blue, 21–40 green, 41–60 yellow, 61–90 brown)
- **Friday Top 20** sheet with top stock names per Friday
